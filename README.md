# React + TypeScript + Vite

Template awal untuk membangun aplikasi **React + TypeScript** menggunakan **Vite** sebagai development server dan build tool.

Template ini menyediakan konfigurasi dasar yang sederhana untuk memulai pengembangan aplikasi dengan cepat, sekaligus menyediakan **Hot Module Replacement (HMR)**, **Oxlint** untuk linting, serta integrasi React melalui plugin resmi Vite.

Dengan template ini, Anda dapat langsung membuat komponen React, menjalankan development server, melakukan pemeriksaan kode, dan melakukan build aplikasi untuk production.

## Fitur Utama

Template ini menyediakan beberapa fitur utama:

- **React** — library utama untuk membangun antarmuka pengguna.
- **TypeScript** — menyediakan static typing untuk meningkatkan keamanan dan kualitas source code.
- **Vite** — development server dan build tool yang cepat dan modern.
- **Hot Module Replacement (HMR)** — memungkinkan perubahan source code diterapkan secara langsung tanpa perlu melakukan reload halaman secara manual.
- **Oxlint** — linter berperforma tinggi untuk membantu menemukan potensi masalah pada source code.
- **React Plugin** — menyediakan integrasi React dengan Vite melalui plugin resmi.
- **Type-Aware Linting** — dapat digunakan untuk melakukan pemeriksaan TypeScript yang lebih mendalam.
